3. Component-by-Component Technical Breakdown

1. Prompt Input & FSM State Machine

Files: PromptInputBar.tsx, WorkflowProgressIndicator.tsx, WorkspacePage.tsx

  • Captures user natural language queries and template clicks.
  • Drives the visual state machine: INTERPRETING → PLANNING → RETRIEVING_DATA → CALCULATING → COMPILING.

2. API Client Bridge

File: api-client.ts

  • Acts as the sole HTTP interface connecting the React single-page app to the SAP CAP backend.
  • Handles request resolution, execution, and local fallback when offline.

3. Security & Multi-Tenant Authorization

File: auth-guard.ts

  • Extracts tenant (organizationId) and scopes (FinanceAnalyst, FinanceManager) from incoming tokens.
  • Enforces tenant boundaries so organizations never view or tamper with each other's dashboards.
  • Rejects unauthenticated requests with HTTP 401.

4. AI Intent Interpretation Engine

Files: ai-service.ts, intent-service.ts, mock-llm-provider.ts

  • Sanitizes prompts against injection attacks (SQL injections, mode overrides, script tags).
  • Extracts approved accounting metrics (total_revenue, total_expenses, net_profit, profit_margin).
  • Rejects out-of-scope queries (e.g. EBITDA, churn, or nonsense queries like "what is quata") upfront with helpful guidance.

5. Planner & Orchestrator

Files: planner.ts, orchestrator.ts, tool-registry.ts

  • Builds a bounded DataPlan with a hard step budget (max 5 steps) preventing infinite AI loops.
  • Only approves allowlisted tools (get_finance_metrics).

6. Finance Data Provider

Files: provider-factory.ts, mock-finance-data-provider.ts, s4hana-odata-finance-provider.ts

  • Retrieves accounting ledger entries on-demand from SAP S/4HANA via BTP Destination or local synthetic golden fixtures.
  • Normalizes ledger items into transient FinanceRecord DTOs.

7. Deterministic Arithmetic Engine (Zero LLM Math)

File: calculation-engine.ts

CRITICAL SAFETY RULE: Financial arithmetic is executed exclusively by compiled, deterministic TypeScript code. The AI is never permitted to calculate totals, subtract expenses, or divide margins.
  • Credit entries (H) add to revenue; Debit entries (S) subtract (refunds).
  • Calculates Net Profit = Revenue - Expenses.
  • Calculates Profit Margin = (Net Profit / Revenue) * 100 with zero-denominator safety guards.
  • Attaches cryptographic/timestamped ProvenanceMetadata.

8. Declarative Visual Renderer & Follow-Up

Files: DashboardRenderer.tsx, KpiCardWidget.tsx, BarChartWidget.tsx, LineChartWidget.tsx, FollowUpPanel.tsx

  • Renders declarative DashboardSpec JSON into SVG charts, KPI cards, and accounting tables.
  • Adapts layouts dynamically based on requested metrics.
  • Processes follow-up visual changes (e.g. "Switch to line chart") instantly without re-querying SAP.

9. Persistence & Lifecycle

Files: dashboard-lifecycle-service.ts, MyDashboardsPage.tsx, sqlite.db

  • Saves and reopens dashboard configurations.
  • Strict Data Retention Boundary: Stores only layout specifications; raw SAP financial rows are never saved to the database.
  • Marks reopened dashboards as STALE until explicitly refreshed.
